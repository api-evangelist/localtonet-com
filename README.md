Localtonet provides secure tunneling services that expose localhost applications to the internet. It offers HTTP/HTTPS, TCP, TLS, UDP, and custom domain tunnels with automatic SSL, enabling developers to share web apps, APIs, and services without port forwarding. Features include file server sharing, proxy servers, mobile proxy rotation, and pay‑as‑you‑go pricing. The platform supports Windows, macOS, Linux, Android, Docker, and more, with a dashboard for monitoring and logs.

**Areas:** Company · Tunneling · DeveloperTools · CloudInfrastructure · Security

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Localtonet: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
